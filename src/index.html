Accordion

Standard accordion (only one open at a time)
CassetteCSS is a distributable CSS framework built with Sass and vanilla JS. Drop in a single <link> and <script> tag — no build step required on the consumer end.
All tokens are CSS custom properties on :root. Override them in your own stylesheet after the framework link — no Sass required. For example: :root { --accent: #7c3aed; }
All modern evergreen browsers. The framework uses CSS custom properties, CSS Grid, and ES modules — no IE11 support.
